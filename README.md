# 🏦 Projeto Agência Bancária

Este é um projeto simples de uma **Agência Bancária** desenvolvido em Java, com o objetivo de simular operações bancárias básicas, como criação de contas, depósitos, saques e relatórios de informações.

## 📋 Funcionalidades

- ✅ Criação de contas (Corrente e Poupança)
- 💰 Depósito
- 💸 Saque
- 📁 Geração de relatório
- 📄 Consulta de saldo

## 🛠️ Tecnologias Utilizadas

- [Java](https://www.oracle.com/java/)
- Programação Orientada a Objetos (POO)
